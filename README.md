# humishum.github.io

Personal site

2025, built with nextjs for simplicity
Template: https://vercel.com/templates/next.js/nextjs-portfolio

## Local development

Use Node 22 and pnpm 10.0.0.

```sh
cd blog
pnpm install --frozen-lockfile
pnpm dev
```

Run `pnpm build` to generate the static site in `blog/out`. Run `pnpm start` from `blog` to preview that build locally.
